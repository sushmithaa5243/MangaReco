# MangaReco 📚

AI-powered manga/manhwa/anime recommendation website built using Python, Streamlit and Machine Learning.

## Features
- Personalized recommendations
- Multi-title selection
- Genre explanations for beginners
- Content-based filtering using TF-IDF
- Similarity recommendations
- Beginner-friendly UI

## Tech Stack
- Python
- Streamlit
- Pandas
- Scikit-learn
- TF-IDF Vectorization
- Cosine Similarity

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
